# Fontes consultadas

- Documento de instruções da entrega: contexto da disciplina e requisitos da Parte 1.
- Repositório do grupo: arquivos de case, arquitetura e base de conhecimento previamente criados.
- Dados simulados de catálogo de streaming produzidos para o caso de prova de conceito.
- Regras de domínio e de avaliação construídas a partir do enunciado da disciplina e do contexto do projeto.

## Observação

Como o caso é um protótipo acadêmico com dados simulados, não há uma fonte pública de produção conectada ao sistema. A intenção foi manter o problema realista e verificável, sem expor dados sensíveis ou depender de uma API externa em ambiente de avaliação.
